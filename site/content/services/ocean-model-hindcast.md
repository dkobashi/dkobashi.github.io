## Overview
Development of long-term hindcast systems for reconstructing historical ocean conditions using numerical models, observations, and atmospheric forcing. Hindcast models are run in chunks (e.g. every year) so that they can be run in parallel; however, the way chunking works is different among computer systems we use (e.g. HPC, AWS, or local server). Hindcast datasets provide the foundation for metocean assessments, operational analyses, environmental studies, and engineering design.

## What I can provide
- Develop and implementation of ocean hindcast systems.
- Run hindcast model for the period ranging from month to decades.
- Hindcast models are run in chunks (e.g. every year) to run in parallel.
- Validate and calibrate the hindcast outputs against observations depending on data availability
- Cloud and HPC deployment (AWS, Slurm, PBS)
